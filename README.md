# تعليم السياقة في الجزائر: تطبيق PWA

تطبيق ويب قابل للتثبيت على الهاتف (Android وiOS) دون متجر تطبيقات.

## الهيكل
- `web/`: التطبيق نفسه (HTML وCSS وJS وService Worker وManifest).
- `content/`: المحتوى المصدر (المراحل، الغرامات، الاختبارات). يُنسخ إلى `web/` عند البناء.
- `src/logic.js`: منطق فتح المراحل وتصحيح الاختبارات وعرض الغرامات المحققة فقط.
- `tests/`: اختبارات المنطق.
- `scripts/build-web.mjs`: ينسخ المحتوى والمنطق إلى `web/`.

## التشغيل محلياً
```
npm test          # الاختبارات
npm run build     # نسخ المحتوى إلى web/
npm run serve     # تشغيل على http://localhost:8080
```

## النشر
التثبيت على الهاتف يتطلب HTTPS. ويمكن رفع مجلد `web/` كما هو على أي استضافة ثابتة تدعم HTTPS، مثل Netlify أو GitHub Pages أو Vercel.

## التثبيت على الهاتف
- **Android (Chrome):** يظهر زر «تنزيل التطبيق» في الأعلى، ويعمل بعد تحميل الصفحة مرة واحدة.
- **iPhone (Safari):** لا يدعم زر التثبيت التلقائي، لذا يظهر للمستخدم إرشاد: زر المشاركة ثم «إضافة إلى الشاشة الرئيسية».

## قبل الإطلاق (إلزامي)
1. التحقق من كل غرامة من نص القانون المنشور في الجريدة الرسمية، ثم تعيين `status` إلى `verified` مع `verified_at` وتعبئة `fine_dza`.
2. استبدال `TO_VERIFY` في `stages.json` بروابط فيديو مراجَعة.
3. مراجعة أسئلة الاختبار من مختص، ثم تغيير `status` إلى `approved` وتعبئة `reviewed_by`.
4. مراجعة الشروط الإدارية مع مدرسة معتمدة.

## ملاحظات تقنية
- التقدم يُحفظ في `localStorage` على الجهاز نفسه. لا توجد حسابات مستخدمين بعد.
- المحتوى يُجلب بطريقة network-first، فتصل التحديثات المعتمدة للمستخدمين، ويعمل التطبيق دون اتصال بالنسخة المخزنة.
- زر التثبيت يظهر فقط عندما يسمح المتصفح بذلك، ولا يظهر إذا كان التطبيق مثبتاً مسبقاً.
